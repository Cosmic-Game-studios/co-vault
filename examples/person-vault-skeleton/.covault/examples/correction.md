## What I assumed
That the user might benefit from a primer on dependency injection when
they asked about wiring up a service.

## What is actually true
The user has 6+ years of experience and uses DI daily. They wanted the
specific syntax for their framework, not the concept.

## How to avoid this in future
Default to assuming senior-level understanding for technical questions.
Only explain fundamentals if the user explicitly says they are unfamiliar
with a topic, or if context (e.g. learning a new language) makes it clear.
